# Audit Anti-Slop #001 — Website Galeri Foto
Tanggal: 2026-09-12 · Mode: AFTER (audit hasil jadi)
Metode: Playwright (WebKit) click-through desktop 1280×800 + mobile 375×812, `contrast-check.py` (WCAG), grep source. Screenshot bukti: `audit-index-1280.png`, `audit-mobile-{index,album,dashboard,detail,tambah,register}.png` (folder temp).
Status: TIDAK ADA file yang diubah sampai pemilik menyetujui nomor.

## Temuan (urut prioritas)

### 1. [HIGH · R-03] Detail foto jebol horizontal di HP — overflow 121px
Bukti: viewport 375px, `scrollWidth` 496 vs `innerWidth` 375; pelanggar: `.action-rail`, `.rail-btn`.
Sebab: `@media (max-width:960px)` membuat rail jadi `flex-direction: row` TANPA `flex-wrap`; 5 tombol sejajar (like/komentar/unduh/edit/hapus) melebar ~495px, memaksa halaman bisa digeser samping.
Usulan fix: `flex-wrap: wrap` + `justify-content: center` pada rail mobile.

### 2. [HIGH · R-03] Baris aksi kartu galeri terpotong di HP
Bukti: di 375px, tepi kanan `.action-btn.danger` (hapus) = 434px > 375px; kartu `overflow: hidden` → tombol share/unduh/edit/hapus admin TERPOTONG dan tak tersentuh.
Sebab: `.photo-actions` tidak wrap; satu kartu ±165–343px harus memuat 5–7 kontrol.
Usulan fix: `.photo-actions { flex-wrap: wrap; }` di ≤640px (atau kurangi tombol yang tampil di kartu, sisanya masuk menu).

### 3. [HIGH · R-02] Em dash (—) masih dipakai di teks UI
Bukti: `<title>"X — Galeri Foto"` di SEMUA halaman (diukur: "Login — Galeri Foto"), opsi `<option>— Tanpa Album —</option>` di tambah.php & edit.php (deteksi browser: true), caption share "X — Galeri Foto" di engagement.php.
Usulan fix: ganti dengan tanda hubung biasa / kurung, contoh: "Login - Galeri Foto", "(Tanpa Album)".

### 4. [HIGH · R-03] Target sentuh di bawah 44px (diukur di browser)
Bukti: `.btn-icon` 34×34, `.action-btn` 39×36, `.nav-link` 88×37, eye-toggle 31×34, `.toast-close` 29×29.
Usulan fix: perbesar AREA SENTUH tanpa mengubah ukuran visual (padding + pseudo-element) pada kontrol kunci; kecilkan daftar bila pemilik menyatakan target desktop saja.

### 5. [MEDIUM · R-10] Glassmorphism melampaui dosis ("accent, bukan karakter")
Bukti: backdrop-filter aktif serentak di navbar + semua kartu + input + chip + rail + toast (sebagian besar elemen layar).
Konteks: ini ARAHAN PEMILIK (tema glass diminta eksplisit + referensi), jadi lolos purpose-test — TAPI alasannya belum ditulis di mana pun, dan tanpa alasan tertulis aturan menilai sebagai slop.
Usulan fix: tulis 1 baris alasan di README (atau DESIGN.md), dan/atau turunkan blur di elemen kecil (chip, input) sisakan glass untuk permukaan besar.

### 6. [MEDIUM · R-04] Set ikon = klon gaya Lucide (tell "AI default")
Bukti: seluruh ikon stroke 2px rounded khas Lucide/Feather. Relevansi tiap ikon terhadap konten BAGUS (folder=album, heart=like).
Usulan fix: cukup tulis alasan pemilihan ikon di README; opsional: ubah stroke 1.75 agar kurang terasa "library default".

### 7. [LOW · C-1] Campur bahasa Inggris/Indonesia di UI
Bukti: login/register penuh Inggris ("Welcome back!", "Sign in to access...", "Log In", "Remember me", "Don't have an account?") vs seluruh halaman lain Indonesia; juga placeholder "—" di no.3.
Usulan fix: samakan satu bahasa (saran: Indonesia konsisten, mengikuti judul tugas UKK) ATAU Inggris konsisten di auth — pilih salah satu.

### 8. [LOW · R-20] Nama brand tidak selaras dengan logo
Bukti: logo resmi bertuliskan "NoxGallery", tetapi navbar/title/footer/README memakai "GaleriFoto / Galeri Foto". Swap-logo-test: identitas terbelah dua.
Usulan fix: seragamkan ke "NoxGallery" (atau balik ke nama tugas) di semua titik.

### 9. [LOW · R-37] Arah desain belum tertulis di project
Bukti: arah ada (referensi login dari pemilik, tema glass, logo resmi) tapi hanya hidup di chat; tidak ada DESIGN.md.
Usulan fix: buat DESIGN.md ringkas (5 baris: tema, font, warna, radius, dosis glass) supaya konsisten & bisa dibaca penguji.
